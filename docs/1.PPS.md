# 📘 PROGRAMMATŪRAS PRASĪBU SPECIFIKĀCIJA
**Projekts:** Tournament Bracket Web Aplikācija  
**Izstrādes valoda:** Python  
**Front-end:** HTML + CSS + Bootstrap (vai ekvivalents)  
**Datu saglabāšana:** JSON  
**Lietotāju autentifikācija:** config file (plain-text paroles)  
**Lomas:** Skatītājs (publisks), Pārvaldnieks (ar login)  
**Turnīra tips:** Single Elimination ar spēli par 3. vietu

---

# 1. Sistēmas apraksts
Sistēma nodrošina tīmekļa platformu turnīra organizēšanai, kas balstīta uz single elimination formātu.  
Pārvaldnieks var:

- pievienot spēlētājus,  
- ģenerēt un labot bracketus,  
- ievadīt rezultātus,  
- pārvaldīt turnīra progresu.

Skatītājs var publiski apskatīt bracketus un rezultātu tabulu.

---

# 2. Funkcionālās prasības

## 2.1. Skatītāja sadaļa (publiska)

### 2.1.1. Turnīra pieejamība
Ja turnīrs nav sākts (`status = "not_started"`), skatītājam tiek parādīts paziņojums:

> **"Pašreiz nav aktīva turnīra."**

Netiek attēloti tukši bracketi vai tabulas.

### 2.1.2. Turnīra nosaukuma attēlošana
Turnīra nosaukums redzams vienmēr, ja turnīrs ir sācies vai notiek.

### 2.1.3. Bracketi
- Single elimination struktūra.
- Automātiski ģenerēti no spēlētāju saraksta.
- "Bye" tiek attēlots kā automātiska uzvara.
- Bracketi atjaunojas pēc katras rezultātu ievades.

### 2.1.4. Rezultātu tabula
Rezultātu tabula tiek kārtota šādi:

#### Fiksētās vietas:
1. Fināla uzvarētājs  
2. Fināla zaudētājs  
3. 3.vietas spēles uzvarētājs  
4. 3.vietas spēles zaudētājs  

#### Pārējie spēlētāji:
Kārtoti pēc:
1. Uzvaru skaita (desc)  
2. Punktu starpības (gūtie – zaudētie) kopsummas (desc)  
3. Alfabētiska kārtība (fallback)

## 2.2. Pārvaldnieka sadaļa (ar autentifikāciju)

### 2.2.1. Autentifikācija
- Lietotājvārdi un paroles glabātas **config failā**.
- Paroles plaintext formātā (klienta norādījums).
- Sesijas autentifikācija pēc login.

### 2.2.2. Turnīra konfigurācija
- Ievadīt un labot turnīra nosaukumu.

### 2.2.3. Spēlētāju pārvaldība
- Pievienot jaunus spēlētājus (tikai “vārds”).
- Dzēst vai labot spēlētājus, kamēr nav sākts 1. raunds.
- Papildu lauki nav nepieciešami.

### 2.2.4. Bracketu veidošana
- Automātiska randomizēšana.
- Automātiska "bye" piešķiršana.
- Manuāla bracketu pārkārtošana pirms 1. raunda (drag & drop vai līdzvērtīgs risinājums).

### 2.2.5. Spēļu rezultātu ievade

Pārvaldnieks var izvēlēties vienu no diviem veidiem:

#### A) Ievadīt skaitliskos rezultātus
- Rezultāts ievadāms abiem spēlētājiem.
- Ja abi rezultāti ievadīti → sistēma automātiski nosaka uzvarētāju.
- Manuala uzvarētāja norāde tiek ignorēta, ja ir rezultāti.

#### B) Manuāli izvēlēties uzvarētāju
- Pieejams tikai, ja **nav** ievadīti rezultāti.
- Izmanto, ja skaitliskie rezultāti nav zināmi.

#### Noteikumi
- "Bye" spēlēm rezultātu ievade nav nepieciešama.
- Uzvarētājs automātiski tiek pārcelts uz nākamo raundu.

## 2.2.6. Turnīra atstatīšana
Divi atsevišķi režīmi:

1. **Atstatīt progresu** – saglabā spēlētājus, dzēš spēles un rezultātus.
2. **Pilns reset** – dzēš visu, t.sk. spēlētājus.

# 3. Nefunkcionālās prasības

## 3.1. Datu saglabāšana
Visi dati tiek glabāti JSON failos:

- turnīra konfigurācija,  
- spēlētāji,  
- spēles,  
- turnīra statuss.

## 3.2. Saskarne
- Bootstrap vai līdzvērtīgs CSS framework.
- Saskarne responsīva mobilajām un desktop ierīcēm.

## 3.3. Pārlūku atbalsts
Atbalstīt jaunākās versijas:
- Chrome  
- Firefox  
- Edge  
- Safari (bez specifiska papildefektu risinājuma)

---

# 4. Datu struktūras

### 4.1. Spēlētājs
```json
{
  "id": <int>,
  "name": <string>
}
```

### 4.2. Spēle
```json
{
  "id": <int>,
  "round": <int>,
  "player1": <player_id | "bye">,
  "player2": <player_id | "bye">,
  "score1": <int | null>,
  "score2": <int | null>,
  "winner": <player_id | null>
}
```

### 4.3. Turnīrs
```json
{
  "name": <string>,
  "players": [...],
  "games": [...],
  "status": "not_started" | "in_progress" | "finished"
}
```

# 5. Lietotāju scenāriji (User Stories)

## Skatītājs
- Vēlos redzēt turnīru, ja tas ir aktīvs.
- Vēlos apskatīt bracketus.
- Vēlos apskatīt rezultātu tabulu noteiktajā kārtībā.

## Pārvaldnieks
- Vēlos ielogoties.
- Vēlos pievienot un labot spēlētājus.
- Vēlos izveidot bracketus automātiski vai manuāli.
- Vēlos ievadīt rezultātus ar punktiem vai manuālu uzvarētāja izvēli.
- Vēlos atstatīt turnīru.

# 6. UI prasības

## Skatītājs
- Ja turnīrs nav aktīvs → informatīvs paziņojums.
- Cilnes: **Bracketi** | **Rezultāti**

## Pārvaldnieks
- Login lapa
- Paneļa sadaļas:
  - Spēlētāji
  - Bracketi
  - Rezultāti
  - Uzstādījumi
  - Atstatīšana

---

# 7. Bracketu noteikumi
- Spēlētāji tiek randomizēti.
- Bye piešķirti automātiski.
- Nākamais raunds ģenerējas pēc katras spēles.
- Pēc pusfināliem automātiski izveido spēli par 3. vietu.
- Bracketi vienmēr tiek atjaunoti automātiski.
