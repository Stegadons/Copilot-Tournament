Nepieciešams izstrādāt tournament bracket web aplikāciju, kas programmēta python. 

Aplikācijā jābūt divām sadaļām: 
1. **skatītājs**, kas var skatīšanas režīmā redzēt turnīra nosaukumu un vai nu pašreizējos bracketus vai rezultātu tabulu (iespēja pārslēgties). Rezultātu tabulā spēlētāji sakārtoti pēc uzvaru skaita, nevis raunda rezultātiem; 
2. **pārvaldnieks**, kas var ievadīt spēlētājus un katra raunda rezultātu. Spēlētāji tiek sakārtoti bracketos automātiski jauktā kārtībā, kā arī spēlētājiem tiek piešķirti bye raundi, ja spēlētāju skaits nav pietiekams pilnam bracketam. Pārvaldniekam ir iespēja manuāli mainīt automātiski izveidoto spēlētāju izkārtojumu pirms turnīra pirmā raunda sākuma. Pārvaldniekam ir iespēja atstatīt pašreizējā turnīra progresu (spēlētāji paliek ievadīti) vai atstatīt visu turnīru. 

Web saskarne jānoformē izmantojot botstrap vai līdzvērtīgu CSS framework. 

Pārvaldnieka sadaļai nepieciešama ielogošanās, skatītāja sadaļa ir publiska. Pārvaldnieka lietotājus un paroles definē konfigurācijas failā. 

Turnīra brckets jāveido pēc single elimination principa ar 3.vietas izšķirošo papildus raundu.
